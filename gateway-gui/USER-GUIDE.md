# XXGU 联机网关（Windows x64 · V336）

双击 `XXGU-Gateway.exe`。无需安装 Python、Qt 或额外的运行库。

1. 填写 **Yuzu 房间服务器地址**（IPv4 或域名）、**服务器 UDP 端口**和房间密码。不要在地址中加入 `http://` 或端口。
2. 选择空闲的 **本机 Citra 接入端口**，点击“启动网关”。
3. 在 Citra 的多人游戏直连中填写窗口显示的 `127.0.0.1` 和本机端口，并使用同一个房间密码。本机多台 Citra 可共用该网关。
4. Yuzu 直接连接原来的 Yuzu 房间服务器。保持网关窗口开启，再进入游戏集会所。

窗口实时显示“已接入 X 台 Citra”。接入数量包含正在加入服务器的 Citra，排除已关闭或正在退出的连接。服务器状态另外显示连接进度：网关启动、等待 Citra，并不代表已经连上远端房间；实际加入成功后才显示“已连接 Yuzu 服务器”。部分连接成功时显示成功数量/当前接入数量。

首次打开时，服务器地址和服务器端口留空，本机 Citra 接入端口默认 8888。关闭窗口时会记住四个输入框的值，下次打开自动恢复，包括主动清空的值。设置位于 `%LOCALAPPDATA%\XXGU-Gateway\settings.ini`，密码使用 Windows 当前用户凭据加密保存。

点击“停止网关”会断开该网关接入的 Citra；关闭窗口也会释放连接和本机端口。窗口没有固定运行时限，不会自动启动、退出或修改模拟器，不写密码原文日志。

不会额外创建房间成员，也不读取或展示玩家列表、聊天消息。每台 Citra 沿用原网关的一对一上游房间连接。

如果本机端口已占用，请更换端口，并在 Citra 中同步修改。如果服务器连不上，请核对 UDP 端口、密码、网络及服务器是否为兼容的 Yuzu v1 房间协议。服务器应为可直连的 IPv4 服务；本版本不支持 IPv6、公共大厅账号验证或自动重连。连接中断后，请在 Citra 中重新加入。

菜单栏“配置”（位于“关于”前）可设置监听地址，默认 `127.0.0.1`：仅允许这台电脑上的 Citra 连接。填写 `0.0.0.0` 可接受所有网卡上的连接，让其他电脑共用此网关；也可以填写本电脑某张网卡的 IPv4 地址，仅通过该地址接入。

选择 `0.0.0.0` 时，本机 Citra 仍填写 `127.0.0.1`，其他电脑填写网关电脑的实际 IP 地址和接入端口，不能填写 `0.0.0.0`。请允许防火墙放行该 UDP 端口；公网接入还取决于网络可达性和端口映射。

点击配置页“保存”后立即记住设置，下次启动网关生效；正在运行的网关需要停止后再启动。关闭配置页而未保存会放弃本次修改。下次打开程序会恢复上次保存的配置，旧版本配置文件自动使用默认本机监听。上游客户端 UDP 源端口由系统自动分配。

窗口顶部菜单栏的「关于」可查看版本、作者与联系方式：点击 QQ 号或 QQ 群号即可复制，点击 GitHub 地址可打开项目主页。

对应源码和构建脚本见随包 `SOURCE-CODE.zip`；许可证及第三方说明随包附带。
