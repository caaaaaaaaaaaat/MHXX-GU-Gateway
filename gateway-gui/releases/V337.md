# V337 · 掉线稳定性修订

针对部分玩家反馈的三人/四人联机频繁掉线，本版放宽了两条最容易误伤的断线判定，并修正网关循环的定时器精度。

- 网关与房间服务器之间的连接在建立后改用 ENet 默认超时（约 30 秒判定）；此前全程沿用 1.5 秒硬断线，一次约一秒的网络抖动就会把整个大厅断开，这是本轮掉线报告的主因。
- 真实 MHXX 房主 beacon 看门狗由 1.5 秒放宽到 3 秒：房主端模拟器在任务加载、换区卡顿时不再立刻解散本地客人；收到掉线帧仍即时切换。
- 网关循环申请 1 毫秒 Windows 定时器分辨率，去除系统默认约 15.6 毫秒的调度抖动。
- 代价说明：房间服务器真正失联时的提示时间从约 1.5 秒延长到约 30 秒，与官方房间客户端行为一致。

本版通过 33 项后端检查、1852 项核心回归（47 组）、142 项传输回环检查及界面保存重开检查。掉线改善需在真实公网多人环境验证；自动测试不等同于现场验收。

下载 `XXGU-Gateway-V337-release-win64.zip`，解压后双击 `XXGU-Gateway.exe`，按照 `使用说明.md` 连接。Windows x64 便携版，无需安装 Python 或 Qt。

本机 Citra 使用窗口显示的地址；使用 `0.0.0.0` 时，其他电脑填写网关电脑的实际 IP 和接入端口，并允许防火墙放行对应 UDP 端口。Yuzu 仍直接加入原房间服务器。

对应源码与构建脚本另见 `XXGU-Gateway-V337-source.zip`。用户包仅含程序和使用说明，开源许可合并在使用说明末尾。
