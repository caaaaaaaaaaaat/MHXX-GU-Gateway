# V339 · 联机稳定性优化

V338 之后，桌面版把网关核心同步到最新一版，重点仍是多人联机的稳定性：少一次误判、少一次连不上，多一分会话语义上的正确。

- **房间满判断以房间服务器的声明为准。** 桌面版从不填写房间席位数，核心收到的就是「未知」。在此之前，未知意味着网关本地不做满员检查，是否放行全部由远端回答；现在网关连上房间后读取它自己声明的席位数，按这个真实数字判断，答复 Citra 的 `0c` 时用的也是它。玩家因此不会再遇到「明明还有位置却被本地拦下」或相反的情形；多故障同时存在时的答复顺序（满 → 密码 → 昵称 → MAC → 主机 ID → 版本）与真实 Citra 服务器保持一致。房间若从不声明，检查保持禁用，行为与旧版完全相同。
- **会话层继续沿用 V338 的稳定策略。** 每客户端队列写满时丢弃那一帧而不是关闭会话、Citra 侧 ENet 使用独立的 4 MiB 重组预算、房间链路超时档案可配置——这三点构成 V338 以来「玩家自身没故障却被网关断开」的主要修复，本版 EXE 全部包含。
- **连接路径去掉了几个会误伤自身的判断。** 监听地址与远端房间地址不再被限制在回环，`--room` 接受域名，命令行默认常驻。桌面版本来就传已解析的 IPv4，因此 Windows 行为与 V338 等价；这些修正主要让同一套核心在命令行与容器部署里不再把自己拦下。

GUI 版本号升为 V339，界面无新增操作项，设置文件与既有格式一致，升级后原有设置继续生效。

本版通过 1882 项核心回归（48 组，含新增的 B339 稳定组）、33 项后端检查、设置读写与 CLI 参数检查，以及隐藏窗口冒烟（创建、定时器、优雅关闭，未启动网络）。掉线是否彻底收敛仍需真实公网多人环境验证；自动测试不等同于现场验收。
