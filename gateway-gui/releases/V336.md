# V336 · 新增监听地址配置

支持《怪物猎人XX》（Citra）与《怪物猎人GU》（Yuzu）跨模拟器联机。本版新增监听地址配置，默认仍为本机接入。

- 在“关于”前新增“配置”菜单，可设置监听 IPv4 地址。
- `127.0.0.1`：仅本机（默认）；`0.0.0.0`：接受所有网卡连接。
- 配置保存后，下次启动网关生效；重新打开程序自动恢复上次设置。
- 兼容旧版配置，升级后默认保持本机监听。
- 保留服务器地址、UDP 端口、房间密码及接入端口记忆功能，密码使用 Windows 当前用户凭据加密保存。

下载 `XXGU-Gateway-V336-release-win64.zip`，解压后双击 `XXGU-Gateway.exe`，按照 `使用说明.md` 连接。Windows x64 便携版，无需安装 Python 或 Qt。

本机 Citra 使用窗口显示的地址；使用 `0.0.0.0` 时，其他电脑填写网关电脑的实际 IP 和接入端口，并允许防火墙放行对应 UDP 端口。Yuzu 仍直接加入原房间服务器。

本版通过 33 项后端检查、1845 项核心回归、配置持久化及界面保存重开检查。真实跨电脑接入仍待局域网验证。

对应源码与构建脚本另见 `XXGU-Gateway-V336-source.zip`。用户包仅含程序和使用说明，开源许可合并在使用说明末尾。
